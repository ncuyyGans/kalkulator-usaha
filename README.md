# Kalkulator Usaha

Aplikasi web responsif untuk menghitung HPP, rekomendasi harga jual, profit, ROI/BEP, menyimpan bahan baku dan resep, serta mencatat transaksi kasir.

## Fitur
- Kalkulator HPP dan harga jual ideal
- Analisis modal, profit bulanan, ROI, dan estimasi balik modal
- Database bahan baku dan produk/resep (localStorage)
- Kasir sederhana dan riwayat penjualan
- Ekspor laporan bisnis ke PDF melalui fitur cetak browser
- Responsif untuk desktop dan mobile

## Jalankan lokal
Buka `index.html`, atau jalankan `npm run dev`.

## Deploy
Repo ini siap diimpor sebagai proyek static site di Vercel tanpa build command.
